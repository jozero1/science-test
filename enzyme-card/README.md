# 효소 탐구 카드 뉴스

`index.html`을 Chrome, Edge, Safari 등 최신 브라우저에서 열면 바로 실행됩니다. 외부 라이브러리·CDN·서버·설치·로그인이 필요 없습니다.

1. 예시를 참고해 활용 사례, 효소 이름, 기질과 반응, 활용 효과를 입력합니다.
2. 사진을 업로드하고 템플릿 3종, 본문 크기, 강조색·글자색, 사진 위치를 선택합니다.
3. 각 카드 아래 PNG 버튼 또는 위쪽의 4장 PDF 다운로드를 누릅니다.

학생이 입력한 내용은 변환·요약하지 않습니다. 줄바꿈은 유지하며 긴 내용은 카드 높이를 늘려 표시합니다. PDF는 한글이 포함된 카드 이미지를 4페이지로 묶습니다. 이미지 비율을 유지하고 자르지 않습니다. 원본 입력값은 새로고침 시 지워집니다.

GitHub Pages를 저장소 루트에서 제공하면 `/enzyme-card/` 경로에서 실행됩니다. 현재 작업 브랜치가 `work`라면 기본 브랜치로 병합한 뒤 Pages 설정에서 배포할 브랜치와 `/ (root)`를 선택하세요. 기존 루트 CO₂ 대시보드는 그대로 유지됩니다.
