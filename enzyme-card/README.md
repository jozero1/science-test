# 효소 탐구 카드 뉴스

`index.html`을 최신 브라우저에서 열면 실행됩니다. 서버·설치·로그인·외부 라이브러리 없이 브라우저에서 처리합니다.

1. 학번(예: 20103), 이름을 필수로 입력합니다.
2. 활용 사례, 효소의 이름, 어떤 반응을 촉매하는가, 활용 효과를 각각 작성합니다. 필수 항목이 비면 PNG·PDF 저장을 막습니다. 기타 내용은 선택이며 카드 안에서는 ‘기타 내용’이라는 제목 없이 작성한 본문만 모두 표시합니다.
3. 저장하려면 사진이 최소 2장 있어야 합니다. 0~1장일 때 PNG·PDF 저장을 막고 추가 안내를 표시합니다. 사진 2~4장을 파일 선택, 드래그 앤 드롭, 캡처 이미지 Ctrl+V(Mac ⌘+V)로 넣습니다. 예시 그림은 ‘이미지 모두 지우기’로 비울 수 있습니다. 순서 변경·개별 삭제를 지원합니다.
4. 템플릿 13종, 기본 글꼴 11개 선택지와 내 글꼴 파일, 항목 제목과 학생 답변의 글자 크기·색상을 각각 선택합니다. 제목은 기본적으로 더 큰 굵은 글자로 표시합니다. 기본 글꼴은 기기의 설치 글꼴을 사용하므로 기기에 따라 대체될 수 있습니다. 내 글꼴 파일(TTF/OTF/WOFF/WOFF2, 최대 10MB)을 업로드하면 브라우저에서 불러와 미리보기와 PNG/PDF에 적용합니다. 한글을 지원하고 사용 허락을 받은 파일을 사용하세요. 글꼴 파일도 외부로 전송하지 않으며 새로고침하면 다시 선택해야 합니다.
5. 사진은 처음에 2~3장 가로 한 줄, 4장 2×2로 놓입니다. 이후 미리보기에서 직접 크기·위치를 편집하고, 이미지 목록에서 각도를 조절하세요. 별도 배치·정렬·전체 크기·자동 복원 도구는 없습니다.
6. 미리보기 사진 오른쪽 ↔ 손잡이는 너비만, 아래 ↕는 높이만 조절합니다. 오른쪽 아래 ⤡ 모서리는 현재 가로세로 비율을 유지합니다. 너비·높이를 따로 조절하면 원본 비율과 달라질 수 있습니다. 이미지 목록의 ‘원본 비율로 복원’ 버튼으로 해당 사진의 원본 비율을 되찾을 수 있습니다. 현재 너비를 기준으로 복원하며 회전은 유지하고, 카드 경계에 닿으면 크기·위치를 맞춥니다. 사진 자체를 잡아 드래그하면 제목 바로 아래부터 위쪽 사진 영역 안에서 위치를 이동합니다. 이미지 목록의 회전 각도 슬라이더로 각 사진을 -180°~180° 자유롭게 돌릴 수 있습니다. 마우스·터치·방향키를 지원하며 다른 사진 위치는 유지합니다. 템플릿을 바꾸어도 사진의 위치·크기·회전은 유지합니다. 조절 손잡이는 저장 파일에 포함되지 않습니다.
7. PNG 또는 PDF로 다운로드합니다. 파일명은 `학번_이름.png` 또는 `학번_이름.pdf`로 자동 설정합니다. 이름의 파일명 금지 문자는 밑줄로 바꿉니다.

입력 내용을 변경·요약하지 않으며 줄바꿈을 유지합니다. 카드와 PNG는 A4 세로 비율을 고정하며 PDF는 실제 A4(210×297mm) 한 페이지입니다. 사진 크기·위치·회전에 따라 남은 아래 공간에 맞춰 항목 제목과 학생 답변 글자 크기를 자동으로 줄입니다. 입력한 내용은 생략하지 않습니다. 화면에 실제 적용 크기를 표시하며, 매우 작아지면 사진 크기나 글 분량을 조절하도록 안내합니다. 그림은 고정 높이 상자 없이 원본 비율로 높이를 계산해 배치합니다. 이미지 목록의 사진별 크기(50~180%)로도 조절할 수 있습니다. 모서리 손잡이와 크기 슬라이더는 현재 비율을 유지하며, 오른쪽·아래 손잡이는 각 축을 따로 조절합니다. 사진을 잘라내지 않습니다. 회전한 사진은 회전 후 크기까지 계산해 카드 영역 안에 배치합니다. 원본 파일 자체에 들어 있는 여백은 제거하지 않습니다. 브라우저에서 최대 변 1,600px로 축소합니다. 파일당 15MB, 4천만 화소까지 지원합니다. 클립보드에 실제 이미지가 있어야 붙여넣을 수 있으며 일반 텍스트 붙여넣기는 그대로 유지합니다.

입력 즉시 미리보기가 갱신되므로 별도의 카드 생성 버튼은 없습니다. 작업은 새로고침 시 지워집니다. GitHub Pages에서 저장소 루트를 배포하면 `/enzyme-card/`로 실행됩니다. 기본 브랜치 배포 시 `work` 변경 사항을 먼저 병합하세요. 기존 CO₂ 대시보드는 변경하지 않습니다.

디자인 템플릿: 보태니컬, 사이언스, 매거진, 포토 노트, 갤러리, 미드나이트, 오션, 사쿠라, 블루프린트, 미니멀, 선샤인, 라벤더, 목련. 목련꽃·벚꽃·라벤더·잎사귀·분자·별·조개·햇살 등 작은 그림과 무늬를 가장자리 여백 안에 그려 본문과 사진을 가리지 않습니다. 배경·테두리·글 영역에 차이를 두며, ‘테두리 디자인 색상’과 ‘본문 색상’으로 색상을 조절합니다.
