# 효소 탐구 카드 뉴스

`index.html`을 최신 Chrome, Edge, Safari 등에서 열면 실행됩니다. 서버·설치·로그인·외부 라이브러리 없이 동작합니다.

1. 카드 제목과 조사 내용을 한 칸에 입력합니다. 활용 사례, 효소 이름, 기질과 반응, 활용 효과와 출처를 자유롭게 정리하세요.
2. 그림 2~4장을 파일 선택, 업로드 영역에 드래그 앤 드롭, 캡처 이미지 Ctrl+V(Mac ⌘+V)로 추가합니다. 이미지 목록에서 순서를 바꾸거나 삭제할 수 있습니다. 예시 그림을 교체하려면 ‘이미지 모두 지우기’를 누르세요.
3. 배경과 배치가 다른 6종 템플릿, 글자 크기·색상, 사진 영역 크기를 고릅니다.
4. 사진을 위에, 글을 아래에 배치한 통합 카드 1장을 PNG 또는 PDF로 다운로드합니다.

템플릿: 격자, 대표 사진+보조 사진, 가로 띠+2단 본문, 엇갈린 포토 노트, 세로 갤러리, 비대칭 사진+본문 상자. 글은 변경·요약하지 않으며 줄바꿈을 유지합니다. 긴 글은 카드 높이를 늘립니다. 이미지 전체를 비율에 맞춰 표시하고, 브라우저 내에서 최대 변 1,600px로 축소해 메모리 사용을 줄입니다. 파일당 최대 15MB, 4천만 화소까지 지원합니다.

클립보드에 실제 이미지가 있어야 붙여넣을 수 있습니다. 일반 텍스트 붙여넣기는 그대로 유지합니다. 브라우저가 이미지 붙여넣기를 지원하지 않으면 캡처 파일을 저장해 파일 선택이나 드래그 앤 드롭을 사용하세요. 클립보드 읽기 권한이나 외부 전송은 요청하지 않습니다.

작업은 새로고침 시 지워집니다. GitHub Pages에서 저장소 루트를 배포하면 `/enzyme-card/` 경로로 실행됩니다. 기본 브랜치 배포 시 `work` 변경 사항을 먼저 병합하세요. 기존 CO₂ 대시보드는 변경하지 않습니다.
