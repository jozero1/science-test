# 효소 탐구 카드 뉴스

`index.html`을 최신 브라우저에서 열면 실행됩니다. 서버·설치·로그인·외부 라이브러리 없이 브라우저에서 처리합니다.

1. 학번(예: 20103), 이름을 필수로 입력합니다.
2. 활용 사례, 효소의 이름, 어떤 반응을 촉매하는가, 활용 효과를 각각 작성합니다. 필수 항목이 비면 PNG·PDF 저장을 막습니다. 기타 내용은 선택이며 작성한 내용은 모두 포함합니다.
3. 사진 2~4장을 파일 선택, 드래그 앤 드롭, 캡처 이미지 Ctrl+V(Mac ⌘+V)로 넣습니다. 예시 그림은 ‘이미지 모두 지우기’로 비울 수 있습니다. 순서 변경·개별 삭제를 지원합니다.
4. 템플릿 6종, 글꼴 5개 계열, 항목 제목과 학생 답변의 글자 크기·색상을 각각 선택합니다. 제목은 기본적으로 더 큰 굵은 글자로 표시합니다. 글꼴은 기기의 설치 글꼴을 사용하므로 기기에 따라 대체될 수 있습니다.
5. 사진 기본 배치는 2~3장 가로 한 줄, 4장 2×2입니다. 모든 사진 한 줄 또는 2열 격자로 직접 바꾸고 반듯하게/살짝 기울이기를 선택할 수 있습니다.
6. 미리보기 사진 오른쪽 ↔ 손잡이는 너비만, 아래 ↕는 높이만 조절합니다. 오른쪽 아래 ⤡ 모서리는 현재 가로세로 비율을 유지합니다. 너비·높이를 따로 조절하면 원본 비율과 달라질 수 있습니다. 사진 자체를 잡아 드래그하면 위쪽 사진 영역 안에서 위치를 이동합니다. 마우스·터치·방향키를 지원하며 다른 사진 위치는 유지합니다. ‘사진 자동 배치로 되돌리기’로 원래 비율·배치를 복원할 수 있습니다. 배치·정렬·전체 크기·템플릿 변경 시 수동 편집을 초기화합니다. 조절 손잡이는 저장 파일에 포함되지 않습니다.
7. PNG 또는 PDF로 다운로드합니다. 파일명은 `학번_이름.png` 또는 `학번_이름.pdf`로 자동 설정합니다. 이름의 파일명 금지 문자는 밑줄로 바꿉니다.

입력 내용을 변경·요약하지 않으며 줄바꿈을 유지합니다. 긴 글은 카드 높이를 늘립니다. 그림은 고정 높이 상자 없이 원본 비율로 높이를 계산해 배치합니다. 이미지 목록의 사진별 크기(50~180%)와 사진 전체 크기로도 조절할 수 있습니다. 모서리 손잡이와 크기 슬라이더는 현재 비율을 유지하며, 오른쪽·아래 손잡이는 각 축을 따로 조절합니다. 사진을 잘라내지 않습니다. 기울인 사진은 회전 후 크기까지 계산해 겹침과 잘림을 방지합니다. 원본 파일 자체에 들어 있는 여백은 제거하지 않습니다. 브라우저에서 최대 변 1,600px로 축소합니다. 파일당 15MB, 4천만 화소까지 지원합니다. 클립보드에 실제 이미지가 있어야 붙여넣을 수 있으며 일반 텍스트 붙여넣기는 그대로 유지합니다.

작업은 새로고침 시 지워집니다. GitHub Pages에서 저장소 루트를 배포하면 `/enzyme-card/`로 실행됩니다. 기본 브랜치 배포 시 `work` 변경 사항을 먼저 병합하세요. 기존 CO₂ 대시보드는 변경하지 않습니다.
